# 文献综述与创新性矩阵

完整的定题、连续文献综述、研究方法和逐章写作设计见 [论文完整研究与撰写方案](论文完整研究与撰写方案.md)。本文件保留逐项阅读与创新边界记录。

检索截止：2026-10-10。用于评估选题，不将已发表论文与预印本混为同一证据等级。会议状态以会议官方页面为准；缺少核验时只标年份或预印本。

阅读标记：**M**＝本轮查看方法／实验或局限相关正文；**A**＝摘要／官方条目级筛选；**R**＝查看官方仓库或数据说明；**D**＝实际下载数据／代码并检查字段；**E**＝实际运行本文所需的评测自检。M 不表示通读全部附录，A 类不作为细节性方法结论依据。本轮覆盖下表 35 项研究文献，另列模型资源；重点深入的是最接近原题的工作及主数据集。

## 1. 检索方法与范围

检索组合包括：

- financial numerical question answering / FinQA / TAT-QA / program of thoughts / executable reasoning；
- financial claim verification / evidence grounding / operand provenance / formula verification；
- selective question answering / abstention / risk coverage / confidence calibration / conformal risk；
- semantic entropy / uncertainty probes / sufficient context / faithfulness；
- numerical perturbation / counterfactual financial benchmark / latent structured alignment / spurious programs。

以检索结果筛选近邻论文，再向其参考文献和作者仓库扩展；额外检查 2026 年工作，以免只引用 2021–2024 年经典论文。纳入能改变选题、基线、数据或评测设计的研究；不依赖商业博客或聚合网站确定论文方法。没有建立 PRISMA 式检索计数，也不能据此宣称完整覆盖全部研究。

## 6. 综述可形成的论文叙述

第一条研究线解决“怎样计算”，第二条解决“证据是否支持”，第三条解决“何时不输出”。它们交叉处已有直接相关研究，因此本论文不再以搭建三模块流水线为贡献。

可检验的剩余问题是：**在证据位置和角色并非唯一确定的条件下，保留并利用绑定的不确定性，能否在有限计算预算下改善固定候选答案的错误排序与选择风险？**

这需要实证证明三件事：其一，绑定信号有独立信息；其二，结构关系带来超过简单特征分类器的增益；其三，收益不依赖同源报告、测试标签或较大调用预算。研究缺口应这样表述为可证伪假设，不写成“现有研究完全忽视了证据绑定”。

## 7. 文献与复现仍有边界

- FinGround 的代码可访问性尚不满足复现前提；不能据此认为其论文方法不存在，也不能把它从近邻讨论删除。
- VeriFin 的派生数据许可证占位文件明确写 pending，GBFR 根目录未发现许可证。本轮仅核验公开可读资源，未将它们作为可自由再发布的主数据。
- GitHub 元数据接口曾返回 403 rate limit，日志已保留；这不是仓库不存在的证据。GBFR 随后用 Git 获取并固定版本。
- 主实验不依赖 DocMath gated 文件、私人金融数据或作者尚未公开的标注。
- 本轮未重新训练或复现上述论文的性能；不同论文的 EM、容差、coverage、生成器及输入证据不一致，不能直接横向拼接成排名。
- 最终开题前还应复查近邻论文版本更新，补读准备正式复现的 A 类基线全文；这不影响当前“原题太宽、需收窄”的判断。
