从毕业论文工作区根目录运行：

```bash
python3 Graduation_Thesis/research/topic_b/audit_public_resources.py
python3 Graduation_Thesis/research/topic_b/validate_public_resources.py
```

两个脚本只依赖 Python 标准库。首次下载需要网络；压缩包缓存在 `Graduation_Thesis/.local/topic_b/`，已有缓存时不再次请求网络。审计脚本不执行下载资源中的代码。重新运行会覆盖当前 JSON；若要保留首次 HTTP 下载证据，先保存原 JSON。脚本的日期和输出名固定于此次审计，未来新审计应同步更新日期和文件名。

核验结论：三个数据集均未发现重复 ID、重复 qrels 配对、qrels 引用缺失 ID，查询 split ID 无交叉；未检查全部来源级/语义近重复。FiQA 空文本对应正相关 qrels 在 train/dev/test 分别为 35/2/1 行，不能静默删除后改变评测口径。

这些文件证明数据可获得及其发布包结构，不证明任何排序、幻觉缓解或微调效果。未下载模型权重，未调用 DeepSeek API。
