# 三问文献地图（2026-10-12）

主要成果：[专题综述](../../../选题2_金融item与chunk长池重排_三问文献综述与研究路线.md)、[XMind导图](../../../选题2_三问文献综述与研究路线.xmind)、[浏览版](三问文献地图_浏览版.html)、[逐篇阅读索引](三问文献阅读索引_20261012.md)。

XMind包含6张画布：总览；RQ1归因（6方向）；RQ2现象与评测（6方向）；RQ3缓解与后训练（8方向）；创新边界与实验落点；外围文献与检索边界。核心三问精选89项，外围26项，合计115项去重工作；同一论文出现在多条方向中不重复计数。

原P01—P80沿用20261011记录；N01—N35为本次纳入统一索引的补充，含本轮新阅读和此前金融专题成果。合并层级为M 88项、A 27项；M只表示关键方法/相关实验或分析核对，不能称为115篇全文精读。C/D分别注明作者资源检查/数据解析。尚无本项目大模型效果或后训练结论。

## 如何使用

用XMind打开项目根目录的`.xmind`文件，切换画布；论文节点默认折叠，展开后可看“做了什么”和“迁移与边界”。节点超链接跳转一次来源，备注保留题名、版本、阅读范围与来源批次。无需XMind时，可打开本目录HTML浏览版，支持展开、折叠和标题查找；也提供OPML作为大纲交换格式。

导图使用XMind JSON容器格式，参考[官方SDK字段定义](https://github.com/xmindltd/xmind-sdk-js/blob/master/src/common/model.ts)及[打包实现](https://github.com/xmindltd/xmind-sdk-js/blob/master/src/utils/zipper.ts)。已做ZIP、JSON、节点ID、文献链接覆盖和OPML结构检查。本机未检测到XMind，未完成原生客户端打开测试；这是格式校验与实际打开验证的区别。

## 文件与维护

| 文件 | 用途 |
|---|---|
| `build_literature_map.py` | 单一内容来源及离线构建脚本；含新增逐篇摘要与方向映射 |
| `literature_registry_20261012.json` | 全部115项阅读层级、一次来源及方向 |
| `mindmap_content.json` | 导图可编辑源数据 |
| `三问文献导图.opml` | 大纲导入备份 |
| `三问文献地图_浏览版.html` | 无外部依赖的本地交互阅读版 |
| `三问文献阅读索引_20261012.md` | 35项补充卡片及原80项方向映射 |
| `artifact_validation.json` | 导图哈希及结构校验记录 |

从项目根目录运行：

```bash
python3 research/topic_b/literature_map_20261012/build_literature_map.py
```

脚本只用标准库，不联网、不安装包、不调用模型；会覆盖派生文件。人工在XMind编辑后应另存副本，以免被复建覆盖。主综述Markdown独立维护，不会被该脚本覆盖。
